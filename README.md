# Tomasmprado Tap

## How do I install these formulae?

`brew install tomasmprado/tap/<formula>`

Or `brew tap tomasmprado/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "tomasmprado/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
